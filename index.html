router.Register("user.create", neo.Mutation(
  func(ctx context.Context, in CreateUserInput) (User, error) {
    user, err := db.CreateUser(ctx, in.Name)
    if err != nil {
      return User{}, err
    }

    router.Events().Publish("user.changes", user)
    return user, nil
  },
))
router.RegisterSubscription("user.changes", neo.Subscription(
  func(ctx context.Context, in NoInput) (<-chan UserEvent, error) {
    raw := router.Events().Subscribe(ctx, "user.changes")

  },

One router, three procedure kinds

Keep the backend shape close to the product shape.

Neo organizes application behavior around typed procedures instead of scattered route handlers. Register the operation once, then call it from Go, generated Go clients, or generated TypeScript clients.

HTTP where it fits, streams where it matters

A small RPC surface that still speaks browser.

Queries can travel over GET or POST, mutations use POST, and subscriptions stream through NDJSON or WebSocket with a shared JSON envelope.

Typed handlers Generic Go procedures keep request and response types visible at registration time.
Middleware Wrap procedure execution for auth, logging, rate limits, tracing, and recovery.
Event broker Start with the in-memory bus, then swap in NATS or any broker implementing Neo's tiny interface.
Safe errors Machine-readable codes reach the client while internal Go errors stay server-side.

Quick start

Ship the first endpoint in a few lines.

Neo uses the standard library HTTP stack, so it can own the server or sit beside your existing handlers.

main.go query procedure 
package main

import (
  "context"
  "log"

  "github.com/Protocol-Lattice/neo"
)

type HelloInput struct {
  Name string `json:"name"`
}

type HelloOutput struct {
  Message string `json:"message"`
}

func main() {
  router := neo.NewRouter()

  router.Register("hello", neo.Query(
    func(ctx context.Context, in HelloInput) (HelloOutput, error) {
      return HelloOutput{Message: "Hello, " + in.Name}, nil
    },
  ))

  log.Fatal(router.ListenAndServe(neo.ServerOptions{
    Addr:   ":8080",
    Prefix: "/neo/",
  }))
}
